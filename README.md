# Angelcho Landing Page

A fullscreen personal landing page for **Angelcho**, built with plain HTML, CSS, and JavaScript.

## Project structure

```text
Angelcho-Site-v1/
├── index.html
├── README.md
├── .nojekyll
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
    └── favicon.svg
```

## GitHub Pages

Upload the **contents** of this folder to the root of the repository so that `index.html` is visible at the top level.

Then configure:

`Settings → Pages → Deploy from a branch → main → / (root)`

## Before final launch

Update the placeholder links in `index.html`:

- GitHub profile
- LinkedIn profile
- Email address
